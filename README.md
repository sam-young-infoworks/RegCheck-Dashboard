# React Mortgage Compliance Dashboard

A comprehensive mortgage compliance dashboard built with React, Recharts, and Tailwind CSS.

## Installation

1. Install dependencies:

```bash
npm install
```

## Running the Application

Start the development server:

```bash
npm start
```

The application will open at [http://localhost:3000](http://localhost:3000)

## Features

- Branch compliance overview with interactive charts
- Policy failure rate heatmap
- Filtering by branch, MLO, loan attributes
- Federal and state policy compliance tracking
- Detailed loan file viewer
- Interactive modals for loan details

## Build for Production

```bash
npm run build
```
